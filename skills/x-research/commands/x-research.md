Use the `x-research` skill in research mode for:

`$ARGUMENTS`

If `$ARGUMENTS` is empty, ask for the topic/domain/account/time window and do
not assume a default topic.

Load `references/search-plan.md`, derive the domain and time window, then write
a compact research plan before executing. The plan must include objective, exact
time window, source mix, candidate probes, paper/project verification path when
relevant, and deliverable shape. Then probe before setting thresholds, combine
follow-circle + keyword + trend + long-form/article sources as appropriate, and
write a concise Markdown briefing with source links. If the request mentions
papers, verify paper links outside X when possible.
